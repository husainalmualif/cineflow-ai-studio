# استوديو سينما فلو الذكي — CineFlow AI Studio 🎬

**المحرك المتكامل للإخراج السينمائي، وصناعة الفيديو بالذكاء الاصطناعي، والمونتاج الإيقاعي، والهندسة التسويقية الشاملة (`Google Flow • Veo 3.1 • Gemini Omni Flash 1.1 • Nano Banana Pro`)**

تم تصميم مهارة **`cineflow-ai-studio`** لتكون الاستوديو الإخراجي والإنتاجي المتكامل لصنّاع المحتوى، والمخرجين، والمسوّقين. تستقبل المهارة فكرتك الخام، أو السيناريو، أو صورة المنتج، أو القصيدة الصوتية، وتحوّلها تلقائياً إلى **مخطط إخراجي سينمائي محكم (`JSON Production Blueprint`)** مقسّم إلى لقطات ذكية قصيرة، مع قفل تام لهوية الشخصيات والمنتجات، ومزامنة دقيقة للشفاه باللهجات العربية والخليجية، وتوليد فوري للبوسترات التسويقية والمنشورات الدائرية (`Instagram Carousels`).

---

## 🌟 أبرز القدرات والمميزات (Key Capabilities)

1. **تغطية شاملة لجميع تصنيفات صناعة الفيديو (`Master Classification Matrix`):**
   - **حسب الغرض (8 مسارات):** الإعلانات التجارية (`Commercials & TVCs`)، الفيديوهات المؤسسية (`Corporate`)، التعليمية والتدريبية (`Educational`)، شروحات التطبيقات والمنتجات (`Explainers`)، شهادات العملاء (`Testimonials`)، الأفلام الوثائقية (`Documentaries`)، تغطيات الفعاليات (`Event Videos`)، وفيديوهات الترفيه والأغاني المصورة (`Entertainment & Music Videos`).
   - **حسب الشكل الفني (5 أنماط):** التصوير الحي الواقعي (`Live-Action`)، الرسوم المتحركة (`2D / 3D Animation`)، الموشن جرافيك (`Motion Graphics`)، البث المباشر (`Live Streaming`)، والفيديو التفاعلي و360 درجة (`360 & Interactive`).
   - **حسب المونتاج الإيقاعي (5 أساليب):** المونتاج السينمائي الدرامي (`Montage Sequence`)، الكليبات المتزامنة (`Music Videos`)، الإعلانات الحركية عالية الأدرينالين (`Commercial Promo`)، المونتاج الفيروسي القصير 10–15 ثانية (`Short-Form Edits / AMV`)، وملخصات الفعاليات الحركية (`Sizzle Reels`).
2. **منظومة خاصة للإنتاج المرئي والصوتي للمراثي والقصائد الحسينية (`Husayni Elegies & Latmiyat Sync`):**
   - فهم دقيق لبحور الشعر الحسيني (`النصاري، الموشح، الطويل/الفايزي، التجليب/الگعدية، الميمر، الأبوذية`) والمقامات (`الصبا، البياتي، الحجاز، اللامي، الكرد`).
   - مزامنة اللقطات السينمائية وحركات الـ `Speed Ramp` مع **قوس الطبقات الصوتية (`المستهل [القرار] ⟵ المقطع الأول [الجواب] ⟵ ذروة الشجن [جواب الجواب] ⟵ القفلة [العودة للقرار والوقف بالسكون]`)** وضربات الصدر (`55Hz Latm`) والدمام والزنجيل، مع التزام صارم بالرمزية البصرية المهيبة (`Identity-Safe Symbolic Cinematography`).
3. **التوجيه الإخراجي المتكامل وقاموس الـ 180+ أمر اختصار (`/macros`):**
   - تحديد تلقائي أو يدوي لـ **نبرة الصوت (`Tone`)**، **لغة الجسد (`Body Language`)**، **نوع الكاميرا والعدسة (`ARRI Alexa 65, RED V-Raptor, Sony Venice, Canon Bokeh, iPhone 16 Pro UGC`)**، **حركة الكاميرا (`/dollyin, /orbit_360, /fpvdrone, /speedramp`)**، و**التناسق اللوني (`Color Grading`)**.
   - **بروتوكول محو اللمسة البلاستيكية (`Anti-AI Sheen Protocol`):** إضافة التحبب السينمائي (`35mm Film Grain ISO 800`) وتفاصيل مسام البشرة والأقمشة الميكروسكوبية مع حظر المظهر الرقمي المصطنع (`--no CGI, no plastic skin, no AI sheen`).
4. **ثبات الهوية البصرية والصوتية (`Character, Product & Voice Lock`):**
   - قفل ملامح الشخصية `@Character_01`، وأبعاد وشعار المنتج `@Product_01`، والهوية الصوتية `@Voice: Name` عبر ميزة **`Ingredients-to-Video`** في Google Flow، مع تطبيق **المصافحة البصرية (`Scene Handshake`)** عبر حفظ الإطار الأخير (`Save frame`) وتمريره كبداية للقطة التالية (`+ Add start frame`).
5. **قفل اللهجات العربية والخليجية ومزامنة الشفاه العصبية (`Lip-Sync Optimization`):**
   - كشف تلقائي للهجة (`البحرينية، السعودية، الكويتية، الإماراتية، العراقية، الفصحى`) مع منع تحريف النص (`Verbatim Script Law`).
   - تقسيم الحوار رياضياً بمعادلة **`Words <= Duration_Seconds * 2.5`** إلى جمل قصيرة (`3–5 كلمات`) تفصلها وقفات تنفس طبيعية `.. [0.3s breath pause]` لتمكين محرك `Lip-Sync` من إغلاق الفم ومحاكاة تعابير الوجه بواقعية تامة.
6. **سلامة النصوص العربية وإطار الخاتمة المعياري (`Outro Safe-Zone Standardization`):**
   - حماية النصوص العربية على المنتجات من التشوه، وتخصيص مساحة أمان بصرية قياسية في مشهد النهاية (`9:16` و`16:9`) لعرض الشعار وحسابات التواصل وزر دعوة الإجراء (`CTA`) دون تداخل مع واجهة المنصات، مع ربط بصري تكراري (`Seamless Loop`) بالمشهد الأول.
7. **التوسع التسويقي الشامل وحوكمة التكلفة (`Marketing Expansion & Credit Guardrails`):**
   - تحويل فكرة الفيديو تلقائياً إلى **بوستر إعلاني (`4:5`)**، وتصميم غلاف واقتباس مجتمعي، و**منشور دائري (`Instagram Carousel`)** من 5 إلى 7 شرائح بالفصحى أو العامية الخليجية.
   - تقليل استهلاك أرصدة التوليد (`AI Credits`) عبر التخطيط النصي المسبق، واستخدام `Nano Banana 2 Lite` (مجاني `0 نقطة`) للصور المرجعية، ومسودة `Omni Flash 360p` مع الترقية المجانية إلى `720p` قبل الرندر النهائي.

## ثانياً: كيفية الاستخدام خطوة بخطوة (How to Use This Skill)

تعمل المهارة بمرونة تامة سواء تحدثت معها باللغة الطبيعية (العربية الفصحى أو اللهجات الخليجية/العراقية) أو عبر أوامر الاختصار السريعة (`/macros`). إليك السيناريوهات العملية:

---

### السيناريو 1: صناعة إعلان تجاري أو فيديو فيروسي قصير (`10–15 ثانية`) مع بوستر وكاروسيل
عندما تريد إنتاج إعلان لمنتج أو خدمة لمنصات `TikTok / Reels / Shorts` مع باقة تسويقية كاملة:

**مثال للأمر (Prompt) الذي تكتبه للوكيل:**
> «صمم لي إعلان 15 ثانية لقهوة مختصة فاخرة باللهجة البحرينية، الحوار: "ويش سر القهوة اللي تعدل المزاج من أول رشفة؟ جربها الحين وعيش الفخامة" مع أوامر `/dollyin /macro /goldenhour /4k /ar 9:16`، وأعطني معه البوستر الإعلاني وكاروسيل إنستجرام»

**ما الذي ستقدمه لك المهارة فوراً؟**
1. **تحليل الانحراف الإبداعي (`Creative Divergence`) و4 بدائل للهوك الأول (`Scene 1 Hook Variants`):** لتجربة أكثر من زاوية جذب في أول 3 ثوانٍ.
2. **قفل الهوية (`Identity Lock`):** تعريف ثابت لـ `@Character_Barista_01` و`@Product_SpecialtyCoffee_01` لمنع تغير شكل الكوب أو الملامح بين اللقطات.
3. **تقسيم الفيديو إلى 3 مشاهد قصيرة ذكية (`4s + 7s + 4s = 15s`):**
   - لكل مشهد: البرومبت الإنجليزي المكدّس من 8 طبقات (`visual_prompt`) جاهز للنسخ إلى `Google Flow`.
   - الحوار العربي مقسّم لمزامنة الشفاه (`"ويش سر القهوة اللي .. [0.3s breath pause] تعدل المزاج"`).
   - هندسة المؤثرات الصوتية (`SFX:` و`Ambient noise:`).
   - مشهد النهاية المعياري (`Scene 3 Outro`) بمناطق آمنة للشعار والـ `CTA`.
4. **التوسع التسويقي الشامل:** برومبت البوستر التسويقي (`4:5`) + نصوص 7 شرائح كاروسيل إنستجرام جاهزة للتصميم.

---

### السيناريو 2: استخدام أوامر الاختصار الإخراجية (`/macros`) للتحكم الفوري بالكاميرا والإضاءة
يمكنك تضمين أي أمر يبدأ بـ `/` داخل طلبك ليقوم المترجم بتحويله إلى قيد فيزيائي صارم في برومبت `Google Flow`:

| فئة التحكم | أشهر أوامر الاختصار (`/macros`) التي يمكنك كتابتها | وظيفتها الإخراجية في الفيديو |
| :--- | :--- | :--- |
| **حركة الكاميرا** | `/dollyin`, `/dollyout`, `/orbit_360`, `/track`, `/craneup`, `/whippan`, `/fpvdrone` | دفع الكاميرا للأمام/الخلف، دوران 360 درجة حول الهدف، تتبع الهدف، رافعة علوية، أو طائرة درون سريعة |
| **العدسات والفوكس** | `/macro`, `/35mm`, `/85mm`, `/anamorphic`, `/shallowdepth`, `/rackfocus` | لقطات ماكرو ميكروسكوبية، عدسات سينمائية عريضة أو بورتريه مع عزل الخلفية (`Bokeh`)، ونقل الفوكس |
| **الإضاءة والألوان** | `/goldenhour`, `/chiaroscuro`, `/neon`, `/candlelight`, `/volumetric`, `/tealandorange` | إضاءة الساعة الذهبية، تباين درامي مظلم، نيون ليلي، ضوء شموع دافئ، أو أشعة ضوء مخترقة للغبار |
| **السرعة والمشاهد الخاصة** | `/slowmotion`, `/speedramp`, `/exploded_view`, `/bullet_time`, `/seamless_loop` | حركة بطيئة 120fps، تسريع وتبطيء منحني على الضربة الإيقاعية، تفكيك ثلاثي الأبعاد للمنتج، أو حلقة تكرار لا نهائية |

### السيناريو 3: الإنتاج المرئي والصوتي للمراثي والقصائد الحسينية (`Husayni Elegies & Latmiyat`)
عندما تكون لديك قصيدة حسينية وتريد بناء الفيديو السينمائي المتزامن مع الطور واللطم الإيقاعي:

**مثال للأمر (Prompt) الذي تكتبه للوكيل:**
> «أريد مخطط فيديو سينمائي عمودي `9:16` مدته 15 ثانية لمستهل قصيدة حسينية على مقام الصبا وبحر الفايزي (58 BPM): "يا طارش الظعن بالله .. خبرني عن أحبابي / على رمل الطف .. عيوني ترعاك يا حسين" مع تطبيق الرمزية البصرية المهيبة ومزامنة اللطم»

**ما الذي ستقوم به المهارة تلقائياً؟**
- تضبط الإضاءة واللون على نمط **`Moody Dark Chiaroscuro`** (رمادي فحمي، كهرماني شموع دافئ، وأحمر قاني عميق).
- تطبّق **الرمزية البصرية الآمنة (`Identity-Safe Symbolic Cinematography`)** مثل الظلال الخلفية (`/silhouette`)، الرايات الحريرية السوداء، الفوانيس، والغبار المضاء دون أي تجسيد لوجوه الشخصيات المقدسة.
- تزامن المشاهد الثلاثة مع **قوس الطبقات الصوتية**:
  1. **المشهد 1 (`المستهل - طبقة القرار`):** حركة دفع بطيئة خاشعة (`/slowpush`) مع أول ضربة صدر (`55Hz Latm`) وصدى `285ms`.
  2. **المشهد 2 (`الذروة - جواب الجواب`):** تبطيء منحني (`/speedramp`) ينزل إلى `0.55x Slow-Motion` في اللحظة الدقيقة لضربة الصدر الجماعية والدمام مع تطاير ذرات الغبار في عمود الضوء (`/godrays`).
  3. **المشهد 3 (`القفلة - العودة للقرار والوقف بالسكون`):** توقف الإيقاع فجأة (`0 BPM Rubato`) مع انسحاب الكاميرا بهدوء (`/dollyout`) وترك مساحة آمنة لعنوان القصيدة بالخط الكوفي الحديث.

---

### السيناريو 4: خطوات التطبيق العملي داخل منصة `Google Flow` (بأقل تكلفة نقاط ممكنة)
بعد حصولك على المخطط من المهارة، طبّقه في **`https://flow.google.com`** عبر الخطوات الأربع التالية:

1. **الخطوة 1 — تأسيس الهوية مجاناً (`Ingredients Setup — 0 Credits`):**
   - افتح تبويب **Images** في Google Flow واختر نموذج **`Nano Banana 2 Lite` (0 نقطة)** لتوليد صورة مرجعية نظيفة للشخصية (`@Character_01`) أو ارفع صورة منتجك الحقيقي (`@Product_01`) على خلفية سادة.
   - من القائمة الجانبية **Characters**، احفظ الشخصية واربط بها الصوت المناسب (`@Voice: Name`).
2. **الخطوة 2 — توليد المشهد الأول (`Scene 1 — Hook`):**
   - اختر وضع **`Ingredients to Video`**، وأضف `@Character_01` و`@Product_01`، ثم الصق `visual_prompt` الخاص بالمشهد الأول.
   - *(نصيحة توفير النقاط)*: جرّب اللقطة أولاً عبر **`Gemini Omni Flash 1.1` بدقة `360p`** ثم اضغط **Upscale to 720p (مجاناً 0 نقطة)**، أو ولّدها مباشرة عبر **`Veo 3.1`** للمشاهد النهائية.
3. **الخطوة 3 — الربط السلس للمشاهد التالية (`Scene Handshake via Save Frame`):**
   - أوقف تشغيل فيديو المشهد الأول عند **الإطار الأخير (`Last Frame`)** واضغط زر **`Save frame`**.
   - للمشهد الثاني، اختر وضع **`Frames to Video`**، وضع الإطار المحفوظ في خانة **`+ Add start frame`**، ثم الصق `visual_prompt` الخاص بالمشهد الثاني لتحصل على انتقال سينمائي متصل 100% بلا أي قفزة في الإضاءة أو الملامح.
4. **الخطوة 4 — التجميع في `Scenebuilder` وإضافة النصوص العربية:**
   - مرّر الفأرة على اللقطات المعتمدة واضغط **`More > Add to Scene`** لترتيبها في التايم لاين، ثم أضف النصوص العربية المصححة (`text_overlay`) في المناطق الآمنة المحددة في المخطط.

### السيناريو 5: التشغيل البرمجي عبر سطر الأوامر (`Python & PowerShell CLI Compiler`)
تتضمن المهارة مترجماً برمجياً آلياً (`scripts/cineflow_compiler.py` و`scripts/Compile-CineFlowBlueprint.ps1`) يمكنك تشغيله مباشرة من الطرفية لتوليد ملفات `JSON` وفحص معادلة الكلمات (`Words <= Duration * 2.5`) وكشف اللهجة تلقائياً:

#### أ) باستخدام Python (على جميع الأنظمة Windows / macOS / Linux):
```bash
# تثبيت متطلبات الفحص والاختبار
pip install -r requirements.txt

# توليد مخطط إنتاجي متكامل بصيغة JSON من الطرفية
python scripts/cineflow_compiler.py \
  --idea "إعلان عطر ملكي فاخر في ليلة ممطرة /dollyin /macro /chiaroscuro /4k /ar 9:16" \
  --purpose "Commercials & TVCs" \
  --format "Live-Action" \
  --style-variant "Commercial Promo" \
  --dialogue "ويش سر العطر اللي يبقى أثره في الذاكرة؟ فخامة أصيلة من أول رشة" \
  --runtime 15 \
  --output examples/generated_perfume_ad.json

# تشغيل اختبارات الوحدات الآلية (Pytest) وفحص جودة الكود (Pylint)
pytest -v tests/test_cineflow_compiler.py
pylint scripts/cineflow_compiler.py tests/test_cineflow_compiler.py
```

#### ب) باستخدام PowerShell (على نظام Windows مباشرة بدون متطلبات خارجية):
```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Compile-CineFlowBlueprint.ps1 `
  -Idea "إعلان قهوة مختصة فاخرة /dollyin /macro /goldenhour /4k /ar 9:16" `
  -Purpose "Commercials & TVCs" `
  -Format "Live-Action" `
  -StyleVariant "Commercial Promo" `
  -DialogueText "ويش سر القهوة اللي تعدل المزاج من أول رشفة؟ جربها الحين وعيش الفخامة" `
  -TotalRuntimeSeconds 15 `
  -OutputPath ".\examples\example_01_commercial_promo.json"
```
